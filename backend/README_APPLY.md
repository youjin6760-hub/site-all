# 선택형 검수 프롬프트 패치 적용 안내

## 이번 수정 내용

1. **검수 항목 선택 > 취소 버튼 추가**
   - `취소` 버튼을 누르면 내용 검수/형식 검수 체크박스가 모두 해제됩니다.
   - 체크가 모두 해제된 상태에서 검수를 시작하면 기존처럼 "선택된 검수 항목이 없습니다" 안내가 뜹니다.

2. **존댓말 문체 검수 완화**
   - 기존의 "존댓말 문어체" 규칙은 `~이다`, `~한다`, `~된다` 같은 문자열만 있어도 과하게 오류로 잡을 수 있었습니다.
   - 이번 수정본에서는 "존댓말 확인"으로 변경했습니다.
   - 단순 문자열 포함이 아니라, 실제 explanation 원문이 학습자에게 노출하기에 반말/구어체/메모체인지 확인하도록 프롬프트를 완화했습니다.
   - choices 원문 인용, SQL/함수명/컬럼명/수식, 최종 문장이 존댓말인 표현은 오류로 잡지 않도록 했습니다.

3. **검수 항목 설명 추가**
   - App.jsx 내부에 각 검수 항목 설명 상수를 추가했습니다.
   - 체크 항목에 마우스를 올리면 설명이 title로 표시됩니다.

## 각 검수 항목 설명

### 내용 검수

| 항목 | 의미 |
|---|---|
| 문제 성립 | 문제를 풀기 위한 필수 정보, 이미지, 표, SQL, 수식 등이 누락되지 않았는지 확인합니다. |
| 정답 검증 | 실제 정답과 answer 값이 일치하는지 확인합니다. |
| 해설 논리 | 해설이 문제 조건과 핵심 개념을 올바르게 설명하는지 확인합니다. |
| 선지-해설 매칭 | 각 선지 번호와 해설 내용이 같은 선지를 설명하는지 1:1로 확인합니다. |
| 이미지 검수 | 문제/선지/해설 이미지가 깨지거나 누락되어 풀이에 지장이 있는지 확인합니다. |
| 표현 오류 | 수식 깨짐, 특수문자 깨짐, 글리프 변형, Markdown 잔여 문법 등을 확인합니다. |

### 형식 검수

| 항목 | 의미 |
|---|---|
| 해설 시작 문장 | 해설 첫 문장이 `정답은 X번입니다.` 형식인지 확인합니다. |
| 선지별 해설 존재 | 일반 문제는 각 선지 해설을 확인합니다. 보기제시형은 보기 ㄱ/ㄴ/ㄷ/ㄹ별 해설이 있으면 정상으로 인정합니다. |
| 선지 해설 형식 | 일반 문제는 `X. 선지 내용` 다음 줄에 `: 설명` 구조가 있는지 확인합니다. 보기제시형은 `ㄱ.`, `보기 ㄱ:`, `ㄱ은 ...입니다.` 같은 보기별 해설 형식을 허용합니다. |
| 존댓말 확인 | 해설이 학습자에게 노출하기에 자연스러운 존댓말인지 확인합니다. 단순히 `~다`가 포함됐다는 이유만으로 오류 처리하지 않습니다. |
| 부정형 예외 | `틀린 것은?`, `옳지 않은 것은?` 같은 부정형 문제에서 정답 선지를 틀린 설명으로 해설하는 정상 케이스를 예외 처리합니다. |
| 결론 문장 | 해설 마지막에 정답 선지를 포함한 결론 문장이 있는지 확인합니다. |
| 따옴표 허용 | SQL 문자열이나 선지 원문 때문에 따옴표가 중첩된 정상 케이스를 오류로 보지 않게 합니다. |
| 정답 문장 중복 | 해설 시작 외 위치에 `정답은 X번입니다.` 문장이 반복되는지 확인합니다. |
| Markdown/백틱 | 사용자 노출 해설에 백틱 또는 `**` Markdown 문법이 남았는지 확인합니다. |
| 긴 해설 수동 검토 | 해설이 너무 길어 스크린샷 검증이 제한된 경우 수동 검토 항목으로 표시합니다. |

## 확인 명령어

백엔드 폴더에서:

```bash
python -m py_compile app.py chatgpt_api.py collect_api.py db_api.py prompt_builder.py prompt_rules.py
```

프론트 폴더에서:

```bash
npm run dev
```


## 보기제시형 문제 처리

문제가 ㄱ, ㄴ, ㄷ, ㄹ 또는 A, B, C처럼 개별 보기를 제시하고, 선택지가 보기 조합을 고르는 형식이면 선지별 조합 해설을 강제하지 않습니다.

예를 들어 선택지가 `1. ㄱ, ㄴ`, `2. ㄱ, ㄷ`, `3. ㄴ, ㄷ`, `4. ㄱ, ㄴ, ㄹ`처럼 구성된 경우에는 1~4번 선지별 해설이 없어도 됩니다. 대신 해설 안에 `ㄱ`, `ㄴ`, `ㄷ`, `ㄹ` 각각에 대한 보기별 판단이나 설명이 있으면 정상으로 인정합니다.

긴 해설 수동 검토는 숨김 처리하지 않고 형식 검수 항목 안에 계속 노출됩니다.
